# Agentic-AI-based-Python-programming-tutor-using-n8n-Rag-
Agentic AI Based Python Programming Tutor (n8n + RAG + LLM)

I developed an intelligent Agentic AI Python Tutor that automatically answers programming questions using lecture notes and study materials as its knowledge base. The system is built using n8n workflow automation, Retrieval-Augmented Generation (RAG), vector embeddings, and a Large Language Model to provide accurate, context-aware responses.

This AI tutor retrieves relevant content from uploaded Python PDFs, processes the information using embeddings, and generates grounded answers instead of generic chatbot responses. The workflow follows an agentic decision-making approach where the system determines when to retrieve knowledge, when to generate answers, and when to decline unsupported queries.

Key Features:

Agentic AI workflow built using n8n
RAG-based document retrieval system
Python lecture notes knowledge base
Vector database for semantic search
Accurate, context-aware responses
Hallucination control (answers only from notes)
Automated PDF ingestion via webhook
Intelligent tutoring for Python concepts
Modular AI agent architecture

Technologies Used:

n8n (Workflow Automation)
Retrieval Augmented Generation (RAG)
Vector Embeddings
LLM Integration (OpenAI / Groq / Gemini)
Webhook-based document upload
AI Agent Design

Use Cases:

Python learning assistant
AI-based academic tutor
Lecture notes Q&A system
Smart programming help agent
Educational AI chatbot
